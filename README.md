## 🌟 Funcionalidades do Site

- 🎨 **Visual Moderno e Responsivo:** Desenvolvido com HTML5 semântico, CSS moderno e Google Fonts (*Outfit* + *Plus Jakarta Sans*).
- 🔍 **Filtros e Busca em Tempo Real:** Pesquisa instantânea por nome, raça ou cidade, com seletores de sexo, porte, idade e situação.
- 📱 **Ficha Completa & Modal de Detalhes:** Visualização ampliada com fotos, histórico, observações de saúde e botão direto para o **WhatsApp**.
- ➕ **Cadastro de Cães no Navegador:** Botão para cadastrar novos cães diretamente na interface com persistência automática no `localStorage`.
- 📊 **Conexão Direta com Google Sheets:** Permite conectar qualquer planilha pública do Google Sheets e importar os dados em tempo real direto pelo navegador via API!

## 🚀 Como Ativar o GitHub Pages

1. Acesse o seu repositório: [https://github.com/Gabriel-Luis-Pacheco/atividade-aula-copia-teste-doadog](https://github.com/Gabriel-Luis-Pacheco/atividade-aula-copia-teste-doadog)
2. Clique na aba **Settings** (Configurações) no topo.
3. No menu lateral esquerdo, clique em **Pages**.
4. Em **Build and deployment > Branch**:
   - Selecione a branch: **`main`**
   - Pasta: **`/ (root)`**
5. Clique em **Save**.
6. Em cerca de 1 minuto, seu site estará no ar na URL:  
   👉 **`https://gabriel-luis-pacheco.github.io/atividade-aula-copia-teste-doadog/`**
