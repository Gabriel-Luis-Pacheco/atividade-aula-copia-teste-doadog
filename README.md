# Doando Cachorros 🐶
> **Subtítulo:** Uma versão demonstrativa inspirada no projeto DoaDog  
> **Plataforma:** Google Apps Script + Google Sheets (Web App)

---

## 📁 Estrutura de Arquivos Criada

- `Code.gs` — Backend em Google Apps Script: mapeia colunas dinamicamente, converte URLs do Google Drive e entrega os dados.
- `Index.html` — Estrutura HTML5 semântica e acessível da vitrine e do modal.
- `Styles.html` — Folha de estilos moderna com paleta suave, responsiva para mobile/desktop e foco acessível.
- `Scripts.html` — Lógica JavaScript no cliente: filtros em tempo real, busca instantânea, contador reativo e modal.
